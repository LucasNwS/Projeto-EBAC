# Projeto-EBAC
Meu primeiro projeto da EBAC
## Como executar o calculadora.sh 
Baixe ou clone este repositório
Dê permissão de execução: chmod +x calculadora.sh
Execute: ./nome_do_arquivo.sh

## Explicação do código python
O arquivo organização_de_clientes.py organiza dados de cientes.
- **Lista ´feedbacks´**: guarda vários comentários de clientes.
- **Dicionário ´cliente´**: guarda as informações de um cliente, (nome, idade e feedback) em pares chave: valor.
- **Laço ´for´**: percorre a lista e imprime cada feedback.
- **´print´**: mostra na tela o nome, a idade e o feedback do cliente.
